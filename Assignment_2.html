Podcast Website Project

Creating a cozy, pastel-themed home for book discussions

Project Overview

For my final project in this Web Programming course, I might want to create a website for a podcast that my friend and I host. The podcast focuses on books and what we’re reading.

The website will act as a hub for listeners to explore episodes and discover the books we talk about.

Website Structure

The website will be simple, pastel-themed, and easy to navigate. It will include:

  • Homepage: Podcast introduction + featured episodes
  • Episodes Page: A list of all podcast episodes
  • Individual Episode Pages: Each page will include:
    • A short summary of the episode
    • Links to all books mentioned
    • Possibly embedded audio or a link to Spotify/YouTube
  • About Us: A page introducing the hosts

Why This Project?

I chose this idea because it combines books with the theme of this course: web design. I also want to create a cozy, welcoming digital space that reflects the tone of our podcast
